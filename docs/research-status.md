# 研究状态与复现边界

**证据截止：2026-10-25。公开归档整理：2026-10-27。** 此文区分历史实验、E91 工程控制以及公开仓库的离线验收，避免将不同版本、不同实验入口拼成一次端到端成功。整理和上传没有新增医学实验，也没有核验当前模型服务健康。

## 这份代码对应什么

公开实现来自 E91 的归档实机 Workflow，30 个节点、41 条边。模型插件配置锁定为 0.0.69，数据库查询插件配置锁定为 0.1.47。四个模型角色在该归档中均使用 `qwen3.8-max-0902`，温度 0.2、输出预算 8192、推理参数 low。早期阶段使用过其他模型；不能用早期的模型称呼代替 E91 实际配置。

公开 DSL 为实际导出的可追溯衍生文件，不包含凭据。它仍引用原工作区的数据库工具身份，其他工作区必须在自己的环境重新授权、绑定并验收。代码公开不代表已有任意环境一键复现，也不代表原服务当前仍可调用。

## 仍未完成

1. **新模型闭环验收。** 在可用的授权环境重新执行固定版本、固定输入的逐节点与完整入口实验，保留首次失败，不能用离线合同通过代替。
2. **独立医学语义评测。** 建立专家标注、绑定层支持/反证、限定覆盖和错映射判定；不以原文命中率或模型自评分代替。
3. **完整关闭核心未决目标。** 保留已接受、未通过和未触发对象，核对反馈后对象实际变化及再次审校，避免将提交或补写计作关闭。
4. **查询词数合同统一。** runtime 可选上限与 SQL typed search 上限不一致。当前归档保留失败基线，默认 6 词；修正需要新版本与实际测试。
5. **自动策略晋升与跨病例学习。** 当前 `action_priority`、`focus_fields` 没有实际接入调度，输出策略候选未自动晋升或持久化。未证明泛化、疗效或自进化。
6. **OMOP 表级实现与数据治理。** 未完成正式表级落库验证、研究时间截点隔离、患者主索引、专家金标准管理或真实病例只读接入。

## 如何报告新实验

每次新批次应记录代码和 DSL hash、模型配置别名及参数、插件版本、输入 hash、初始拆解是否固定、词表版本和执行入口。保留每次请求的状态、输入/输出关联、真实查询回执、对象修订、再审校结果、耗时与 token。失败请求的未知用量保留为未知，不把缺失填为 0。

分别报告：漏项、错映射、实际语义修复、退步、未完成闭环、格式恢复、内部关系降级、应用状态和资源消耗。代码门禁误拒的修复应计入工程控制；同一概念 ID 的主张降级与措辞变化不能自动计入医学语义修复。新的完整入口实验与冻结来源的下游链需要分层展示，不混算。

本仓库不分发真实病历或词表整库。上传、云模型处理或后续真实数据使用需要遵守数据持有者既有授权与适用安排，合成示例不构成真实数据授权。
